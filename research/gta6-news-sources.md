# GTA 6 news sources — where to check, and how much to trust each

Rule: **a fact goes in a script only if it traces back to Tier 1 or Tier 2.** Tier 3 is for finding stories; Tier 4 is never stated
as fact.

## Tier 1 — Official (state as CONFIRMED)
| Source | URL | What it gives | Readable from this workspace? |
|---|---|---|---|
| Rockstar Newswire | https://www.rockstargames.com/newswire | Announcements, dates, patch notes, bonuses | ✅ |
| GTA VI website | https://www.rockstargames.com/VI | Trailers, Extended Look, characters, places, screenshots | ✅ |
| Rockstar YouTube | https://www.youtube.com/@RockstarGames | Trailers + transcripts | ✅ (details/transcripts via Firecrawl; downloads blocked) |
| Rockstar on X / Instagram | @RockstarGames | Teasers, launch posts, images | ⚠️ search snippets only — user checks the app |
| Rockstar Support | https://support.rockstargames.com | Footage policy, known issues, launch fixes | ✅ |
| PlayStation Blog | https://blog.playstation.com | Pre-load, editions, PS5 details | ✅ |
| Xbox Wire | https://news.xbox.com | Xbox pre-load, editions | ✅ |

## Tier 4 — Never state as fact
- Leaks (2022 leak and later), datamined pre-load files, "insider" accounts, random TikTok/Instagram claims.
- At most: "there's an unconfirmed rumour that…" — and never show leaked footage.

## After launch (19 Nov) add
- Reviews (IGN, GameSpot, Eurogamer, Game Informer…) — the best "what's new" lists.
- Rockstar patch notes + Support known-issues page.
- Streamers' gameplay (what's actually in the game) — footage only with permission.
